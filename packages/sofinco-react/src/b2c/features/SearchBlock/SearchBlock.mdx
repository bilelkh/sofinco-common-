# SearchBlock

Site-wide search block: a search input, a summary line, two tabs (offers / Q&A) and a paginated result list.

The component is fully controlled by props — pagination links are plain `<a>` tags pointing back at `action` so it works with server-driven search (Jahia, etc.).

## Usage

```tsx
import { SearchBlock } from "sofinco-react";

<SearchBlock
  title="Que recherchez-vous ?"
  action="/search"
  initialQuery="prêt"
  results={hits}
  smartResults={smart}
  nbResults={12}
  smartNbResults={4}
  currentPage={1}
  totalPages={3}
/>;
```
