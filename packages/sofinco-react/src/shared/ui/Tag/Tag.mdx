# Tag

Small pill-shaped, uppercase label — used to identify an argument category
(e.g. "CARTE", "CRÉDIT") above a descriptive text.

## How It Works

- `children` — the label text (uppercased via CSS).
- `className` — additional class (e.g. to add spacing specific to the usage
  context).
