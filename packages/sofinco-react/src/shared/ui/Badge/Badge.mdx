# Badge

A compact reusable badge component to highlight short contextual labels.

## How It Works

- `label` defines the displayed content
- `variant` controls semantic colors
- `className` allows custom layout from parents

## Usage

```tsx
import { Badge } from "sofinco-react";

<Badge label="Prêt perso" />
<Badge label="Nouveau" variant="primary" />
```
